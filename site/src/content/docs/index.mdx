Each repo describes itself in a `sprig.yaml` file: its apps, its infra and the inputs it takes. Sprig runs it where it's checked out (`main`), or checks any branch out in a slot of worktrees of its own, so several branches can be up at once without stepping on each other.

## From a terminal

```sh
sprig init            # make the repo in this folder runnable
sprig up              # run it where it's checked out
sprig up -b feat-x    # run a branch in a slot of its own
sprig ps              # see what's running
```

Sprig runs on Windows. Data lives in `%LOCALAPPDATA%\sprig`.
